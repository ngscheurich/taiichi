# Write idiomatic prose

All plain-language text, e.g. documents, code comments, commit messages, must be crafted with a cohesive, inclusive style. This requires adherence to a prose style guide. If the user did not provide one, see if one exists in the project — `docs/style/prose.md` is a common location. When no guide turns up, fall back to the included one: [style.md](style.md).

Follow the guide explicitly and ask the user when there is uncertainty.
